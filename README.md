# Soko House

**Made of here. Worn everywhere.**

A fictional contemporary African fashion and lifestyle storefront, designed as a portfolio project.

## Creative direction
Editorial meets neo-brutalism: expressive typography, asymmetrical layouts, warm neutral colours and campaign-led photography.

## Stack
- Next.js 16 / React 19 / TypeScript
- Custom CSS design system
- Framer Motion (reserved for future interaction work)
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

## Project status
Milestone 01 — responsive editorial storefront homepage. Product catalogue and shopping interactions are illustrative; checkout, inventory and newsletter services are not connected.

## Brand
Soko House is a fictional concept brand. Product names, prices and brand copy are for demonstration only.
